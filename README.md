# Advertising Sales Data Analytics Project

## Overview
This project performs an exploratory data analysis (EDA) on advertising spending across TV, Radio, and Newspaper channels to evaluate their correlation with sales performance.

## Repository Structure
- `Advertising.csv`: Input dataset containing media budget and sales numbers.
- `main.py`: Python script executing data processing, summary statistics, and visualization generation.
- `requirements.txt`: Python package dependencies.
- `README.md`: Setup and execution guide.
